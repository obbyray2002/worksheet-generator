How to use

  1. Pick a preset, or tick the major keys you want.
  2. Tick the clefs to include: treble, alto, tenor, and/or bass.
  3. Set how many signatures belong on the page. 15 uses each chosen key once if the pool is large enough; a higher number will repeat.
  4. Randomize draws a new set from those options.
  5. Save the quiz as a .json file next to the lesson if you want that exact mix again.
  6. Print from Chrome: Letter, Landscape, headers off, 100%.
