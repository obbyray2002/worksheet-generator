How to use

  1. Pick a preset, or tick the starting pitches you want. C♭ is included.
  2. Set how many questions belong on each quiz. 50 fills one portrait sheet at normal type.
  3. Use Font size if the type should be bigger, and Copies per page to print the same quiz two or four times on one sheet (cut apart). With 2 or 4 copies, drop the question count so they still fit.
  4. Randomize draws a new set. The mix stays weighted toward major/perfect and minor/diminished, with fewer augmented intervals.
  5. Save the quiz as a .json file if you want that exact mix again.
  6. Print from Chrome: Letter, Portrait, headers off, 100%.

Students write the correctly spelled note above the given pitch. The answer key fills in those spellings (double sharps as 𝄪, double flats as ♭♭).
