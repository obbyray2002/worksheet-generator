How to use

  1. Type the title, instructions, and an optional time limit.
  2. Choose how many copies fit on a letter page (1, 2, or 4) and how many boxes are in each row. Use 8 boxes for a full major scale (given note plus seven more).
  3. Enter each given note in the first column. Fill the other boxes if you want an answer key later.
  4. Save the quiz as a .json file next to your lesson materials. Open that file whenever you need it — you do not have to rebuild major scales or tetrachords from scratch.
  5. Randomize shuffles the rows once. Every copy on the page uses that same order, so you can cut a 4-up sheet into identical quizzes.
  6. Print the worksheet or the key from Chrome. Turn off Headers and footers, paper size Letter, scale 100%.

Click ♯ ♭ ♮ to insert an accidental into the box you are typing in. Paste rows accepts a spreadsheet copy: first column is the given note, the rest are answers.

Back up this folder if you move computers. Your quizzes are the JSON files you saved, not the app itself. Pictures in cells are not in this version yet.

Paste rows

Paste from a spreadsheet or type one item per line. Columns can be separated by tabs or commas. The first column is the given note.
