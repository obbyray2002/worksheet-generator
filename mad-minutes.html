How to use

  1. Pick a preset or tick the clefs, accidentals, letters, and octaves you want.
  2. Set how many notes belong on the page. Your current PDFs use 30 (C series) or more on the denser pages.
  3. Randomize draws a new set from those options. Every note comes from your labeled photo folder.
  4. Save the quiz as a .json file next to the lesson if you want that exact mix again.
  5. Print the worksheet or the key from Chrome. Turn off Headers and footers, paper size Letter, orientation Landscape, scale 100%.

Students write the note name under each staff. The key can show C, F♯, B♭, or C4 / F♯5 if you turn on octave numbers.

The photo set includes treble, bass, alto, and tenor. A few pitches are missing from alto and tenor; those simply will not appear.
