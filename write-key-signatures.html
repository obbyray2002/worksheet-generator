How to use

  1. Pick a preset, or tick the major keys you want.
  2. Set how many signatures belong on the page. 15 fills one portrait sheet (two columns) if the pool is large enough; a higher number will repeat and the staves will shrink.
  3. Randomize draws a new set from those options.
  4. Save the quiz as a .json file next to the lesson if you want that exact mix again.
  5. Print from Chrome: Letter, Portrait, headers off, 100%.

Each box names the key with the proper accidental (E♭, F♯, C♭) and shows a blank treble staff. Students write the signature on the staff. The answer key swaps in the completed signature.
