Worksheet Generator

Share with other teachers

This is one static website: HTML, photos, and your saved .json quizzes. Weebly cannot host the photo folder by itself, so publish the whole Worksheet Generator folder somewhere that serves files (GitHub Pages, Netlify, or a school server), then embed that address on Weebly.

  1. Upload this entire folder (do not skip the notes and keys photo folders).
  2. Confirm you can open index.html on that host in a browser.
  3. On Weebly, add an Embed Code block and paste:

Teachers then pick a worksheet type from the menu, click Randomize, and print from Chrome: Letter, headers off, 100%. Identify-notes pages print landscape; the others print portrait.
